# 🕊️ PigeonUI – Android Email

<img src="images/imagegmail_png.png" width="500"> 

---

PigeonUI is a **Gmail-inspired Android application** developed with a full **MVVM architecture**, Node.js backend, and **MongoDB database**. It provides a user-friendly interface for registration, login, and future email management, simulating a typical Gmail user experience.


### ✨ Features
- Email Inbox
- Compose / Send Messages
- Labels and Folders
- Local Caching with Room
